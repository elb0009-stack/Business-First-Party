BUSINESS FIRST PARTY WEBSITE
Files: index.html (content), style.css (design), script.js (interactions).

PUBLISH WITH GITHUB PAGES:
1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select main and / (root), then Save.
6. GitHub will provide the published website address.

The page uses Google Fonts and Unsplash photography, so those assets need an internet connection. Replace the sample party names in the how-to-vote card with the actual parties on your class ballot. This is a fictional classroom project and is not affiliated with the Liberal Party of Australia.
